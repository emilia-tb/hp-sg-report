# Hearing Partners Singapore — SEO Report (August 2026)

Editable Next.js (App Router) presentation with React slides and Recharts charts.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Navigate with ← / → / Space, or `?slide=N` / `#slide-id`.

## Edit content

All metrics and copy live in **`src/data/report.ts`**. Slide layout/components are in `src/components/slides/`.

## Build

```bash
npm run build
npm start
```

Ready for Vercel (framework: Next.js). Do not commit `.env*` or `.vercel`.
